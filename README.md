# ecommerce-customer-analysis
高级数据分析小组项目：电商客户行为分析、客户分群与未来14天购买预测。

## 项目目标
分析电商客户的历史行为与商品类目偏好，构造客户行为特征，
比较简单基线与预测模型对未来14天购买行为的识别能力。

## 数据说明
使用 Synerise 公开电商行为数据，包括：
- 页面访问
- 搜索
- 加入购物车
- 移出购物车
- 购买
- 商品属性

原始数据保存在 `data/raw/`，不上传 GitHub。
数据来源：https://recsys.synerise.com/data-set

## 分析原则
1. 保留原始文件，清洗和分析结果另行保存。
2. 区分行为记录数、用户数与商品数，不将购买记录直接视为订单数。
3. 预测特征仅使用预测时点之前的信息，防止数据泄漏。
4. 价格字段为价格档位，不用于计算实际销售额。
5. 页面访问缺少明确的商品映射，不构造同一商品的完整浏览转化漏斗。
6. 模型比较使用一致的评价条件，并报告限制与错误案例。
